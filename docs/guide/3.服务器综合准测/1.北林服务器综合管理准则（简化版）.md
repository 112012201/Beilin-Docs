## 核心行为规范（必读）

### 通用条款（游戏内+群聊）

1. **禁止违法敏感内容** — 不谈政治、黄赌毒，不传播违规信息 → Ⅴ级封禁
2. **禁止人身攻击** — 不骂人、不侮辱、不嘲讽
3. **禁止刷屏** — 不重复发无意义消息
4. **禁止无关广告** — 不发商业广告/砍价链接（可发其他服务器宣传）
5. **禁止散布谣言** — 不编造虚假信息
6. **禁止骚扰他人** — 不让人不适，不私聊骚扰
7. **禁止恶意曲解规定** — 不误导新人
8. **尊重管理员** — 有异议私下说，不公开挑衅

### 服务器特有

9.  **禁止网络攻击** — DDoS/假人压测等 → 永久封禁+法律责任
10. **禁止外挂** — 作弊客户端 → 永久封禁
11. **禁止毁坏他人建筑** — 误毁立即修复；故意严惩
12. **公共区域禁建无意义建筑** — 未报备区域建造即拆
13. **线路建设时效** — 申请后60天内须开工，否则释放编号
14. **未建线路限制** — 每人同时最多3条未建线路
15. **手机免责** — 手机端问题自行承担，无技术支持

### 群聊特有

16. **群聊内容** — 不刷屏灌水，不发恐怖血腥图
17. **文件安全** — 不发病毒/外挂/钓鱼链接 → 传播即永久封禁
18. **语音频道** — 不干扰他人
19. **禁止转发** — 不把本群聊天记录转出去
20. **禁止擦边内容** — 严禁黄色、时政擦边、伪造信息

## 处罚等级速查表

| 等级 | 典型措施 |
|:----:|:---------|
| **Ⅰ级** | 口头警告 / 禁言20分钟–3天 |
| **Ⅱ级** | 禁言1–7天 / 临时封禁1–3天 / 移出群聊1–7天 |
| **Ⅲ级** | 禁言7–15天 / 临时封禁3–7天 / 移出群聊7–15天 |
| **Ⅳ级** | 临时封禁7–15天 / 移出群聊15–30天 / 资产移交 |
| **Ⅴ级** | 永久封禁 / 永久移出群聊 / IP封禁 |

## 重要补充

### 三次警告转临时封禁

::: warning 累计加重
累计收到**3次警告**后，再次违规可直接**临时封禁1–3天**。（警告包括口头警告和Ⅰ级处罚）
:::

### 申诉渠道

对处罚有异议 → 3日内私聊管理或申诉专线 → 48小时内复核
